# Scripts

Rendering and visualization utilities for the QNG workspace.

Notable entries:

- `qng_visualize_ether_3d.py` — technical 3D scatter/slice visualizer for the older ether views
- `qng_animate_ether.py` — GIF animator for slice evolution
- `qng_render_hopfion_ether.py` — static cinematic renderer for the latest `v7 + hopfion` ether interpretation

Example:

```powershell
py scripts/qng_render_hopfion_ether.py --save scripts/ether_hopfion_v7.png
```
