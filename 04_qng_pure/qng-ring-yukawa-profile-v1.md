## Section 1: The Screened Poisson Equation

From DER-QNG-012 §5, the quasi-static coherence field satisfies:

```
D_diff₀ ∇²δ_C − Γ₀ δ_C = S_src
```

Equivalently, with screening length λ² = D_diff₀/Γ₀:

```
(∇² − 1/λ²) δ_C = S_src / D_diff₀
```

The Green's function for (∇² − κ²) G = δ³(r) in 3D is:

```
G(r) = −exp(−κ r) / (4π r) = −exp(−r/λ) / (4π r)
```

Therefore the general solution is:

```
δ_C(x) = − (1 / (4π D_diff₀)) ∫ [exp(−|x−x'|/λ) / |x−x'|] S_src(x') d³x'
```

The sign is correct: S_src > 0 (matter depletes coherence) gives δ_C < 0 near matter,
consistent with GRAV-C1 (Φ_Newton = −(πz/β) δ_C < 0 near matter → attractive).

## Section 2: Thin Vortex Ring Source Model

A thin vortex ring of major radius R centered at the origin in the z=0 plane, with
total integrated source strength Q_ring, is modeled in cylindrical coordinates (ρ,φ,z):

```
S_src(ρ', φ', z') = Q_ring × δ(ρ' − R) × δ(z') / (2π R)
```

This is the leading-order model (thin core, r_core → 0). The finite core gives corrections
at scales r ~ r_core ~ 2 lattice units (subdominant for galaxy-scale r >> R >> r_core).

Q_ring has dimensions [D_diff₀ × lattice-unit], so the ratio Q_ring/D_diff₀ has
dimension [lattice-unit], consistent with δ_C being dimensionless.

**Substituting into the general solution:**

```
δ_C(ρ, z) = − (Q_ring / (8π² D_diff₀)) ∫₀²π [exp(−d(u)/λ) / d(u)] du
```

where (using azimuthal symmetry, placing the observation point at φ=0):

```
d²(u) = ρ² + R² + z² − 2ρR cos(u)
```

## Section 3: The Ring Yukawa Profile Function K_ring

**Definition:**

```
K_ring(ρ, z; R, λ) ≡ (1/2π) ∫₀²π exp(−d(u)/λ) / d(u)  du

with  d²(u) = ρ² + R² + z² − 2ρR cos(u)
```

The chi-field (coherence deviation) outside the ring is then:

```
δ_C(ρ, z) = − (Q_ring / (4π D_diff₀)) × K_ring(ρ, z; R, λ)
```

The rotation curve velocity contribution is:

```
ΔV²(ρ) = G_QNG × ρ₀ × A_ring × K_ring(ρ, 0; R, λ)
```

where A_ring absorbs the conversion between Q_ring and physical mass (open: requires rho_0).

**Relation to DER-QNG-027:**  
The "C_K(r)" used in DER-QNG-027 (step 7) was the point-source limit K_ring → exp(−r/λ)/r.
This derivation replaces that approximation with the correct ring geometry.

## Section 4: Key Limits

### 4.1 On-axis (ρ = 0) — exact closed form

When ρ = 0: d(u) = √(R² + z²) for all u (independent of u). Therefore:

```
K_ring(0, z; R, λ) = exp(−√(R²+z²) / λ) / √(R²+z²)
```

**This is exact.** On the symmetry axis, the ring acts like a single point source at
distance √(R²+z²). This gives the cleanest test of K_ring numerically.

### 4.2 Far field (r ≡ √(ρ²+z²) >> R) — Bessel approximation

Expand d(u) for r >> R:

```
d(u) = r × √(1 − 2(ρR/r²)cos u + (R/r)²)
     ≈ r − (ρR/r)cos u + O(R²/r)
```

Then:

```
exp(−d/λ)/d ≈ [exp(−r/λ)/r] × exp[(ρR cos u)/(rλ)] × (1 + (ρR/r²)cos u + ...)
```

Averaging over u:

```
K_ring(r >> R) ≈ [exp(−r/λ)/r] × I₀(ρR / (rλ))
```

where I₀ is the modified Bessel function of the first kind, order 0.

**For r >> R: ρ/r ≤ 1, and (ρR)/(rλ) ≤ R/λ = 4/3.41 ≈ 1.17 at most (at r=R).**
At r >> R this ratio → 0, so I₀ → 1 and K_ring → exp(−r/λ)/r.

**Conclusion:** At large r, the ring source reduces to the point-source Yukawa — the
same as used in OBS-004. The OBS-004 failure (λ→∞ best fit) is therefore a genuine
physical finding, not a profile artifact.

### 4.3 Equatorial plane far field (z = 0, ρ >> R) — amplitude correction

At z=0, ρ >> R: d(u) ≈ ρ − R cos(u). Expanding exp(−d/λ)/d:

```
K_ring(ρ, 0; R, λ) ≈ [exp(−ρ/λ)/ρ] × I₀(R/λ)
```

**The factor I₀(R/λ) corrects the point-source amplitude.**

For substrate parameters β=0.35, z=6, α=0.005:
```
λ = √(β/(zα)) = √(0.35/0.03) = 3.41 lattice units
R = 4 lattice units (CPU-043 ring)
R/λ = 1.173
I₀(1.173) ≈ 1.384
```

**The ring source gives 38% more chi-field amplitude than a point source of the same Q_ring.**
This is a geometric correction that was absent from all OBS tests so far.

### 4.4 Coulomb limit (λ → ∞) — elliptic integral

When λ → ∞: exp(−d/λ) → 1, and:

```
K_ring(ρ, z; R, ∞) = (1/2π) ∫₀²π du / √(ρ²+R²+z²−2ρR cos u)
                    = (2/π) / √((ρ+R)²+z²) × K(k)
```

where K(k) is the complete elliptic integral of the first kind with:

```
k² = 4ρR / ((ρ+R)² + z²)
```

This is exact electrostatics of a uniformly charged ring — well known.

**Key subcases:**
- ρ >> R (far exterior): k → 0, K(k) → π/2, K_ring → 1/ρ (Coulomb at large r)
- ρ << R (interior): K_ring → (1/R) × constant (flat inside ring)
- ρ = 0: K_ring = 1/√(R²+z²) — matches §4.1 with λ→∞

## Section 5: Failure Mode of OBS-001 through OBS-004

### OBS-001 and OBS-002: Flat profile (K_ring = const)

The flat profile corresponds to λ → ∞ AND uniform source. But even in the Coulomb
limit, K_ring → 1/ρ at large radii — NOT flat. The flat prediction requires summing
over a specific radial distribution of rings that produces a 1/ρ² volume density,
which then integrates to ΔV² = const. This was never derived — it was assumed.

**Finding:** The flat profile is not the Coulomb limit of K_ring for a single ring,
and not derivable for a distributed source without specifying the source density profile.

### OBS-004: Point Yukawa (K_ring = exp(−r/λ)/r)

This IS the correct far-field (r >> R) limit (§4.2). The OBS-004 result (best-fit λ→∞)
is therefore physically meaningful: it says that for the galactic rotation curve sample,
the chi-field profile that fits best has λ larger than the galaxy scale.

This is consistent with the Newtonian limit program: λ_screen must be cosmological
(N4 open gap: why α takes its physical value).

**Finding:** OBS-004 tested the right functional form. Its failure (λ→∞) is a signal
about the theory, not an artifact of the wrong profile. The missing piece is a_M per
galaxy correlating with baryonic mass.

## Section 6: Numerical Evaluation Formula

For implementation in QNG-OBS-005 (proposed):

```python
def K_ring(rho, z, R, lam, n_gauss=128):
    """
    Ring Yukawa profile: chi-field at (rho, z) from ring of radius R,
    screening length lam. All in lattice units.
    """
    import numpy as np
    u = np.linspace(0, 2*np.pi, n_gauss, endpoint=False)
    d = np.sqrt(rho**2 + R**2 + z**2 - 2*rho*R*np.cos(u))
    integrand = np.exp(-d / lam) / d
    return np.mean(integrand)


def K_ring_axis(z, R, lam):
    """Exact on-axis value (rho=0)."""
    import numpy as np
    d = np.sqrt(R**2 + z**2)
    return np.exp(-d / lam) / d
```

**Convergence:** 128 Gauss points is sufficient for ρ/R < 10. For ρ/R > 10, the
far-field approximation K_ring ≈ exp(−r/λ)/r is accurate to better than 1%.

## Section 7: Connection to Galaxy Rotation Curves

For a galaxy with N_ring vortex rings distributed with surface density Σ_ring(R_gal),
the total chi-field in the disk plane (z=0) is:

```
χ_total(ρ_obs) = ∫ K_ring(|ρ_obs − ρ'|, 0; R, λ) × Σ_ring(ρ') × Q_ring  d²ρ'
```

This is a 2D convolution of the ring surface density with K_ring.

For a uniform thin disk with Σ_ring = const and ρ_obs >> disk_size >> R:
- K_ring → exp(−r/λ)/r (far field)
- The convolution gives the standard Yukawa halo profile
- Flat rotation curve requires λ >> disk_size

**The three cases for galaxy-scale chi-field:**

| Regime | K_ring approx | V_circ profile |
|--------|--------------|----------------|
| r >> λ >> R | ≈ exp(−r/λ)/r | Falls exponentially |
| λ >> r >> R | ≈ 1/r (Coulomb) | V² ∝ M(r)/r → needs ρ ∝ 1/r² for flat |
| λ >> R (disk), r ~ λ | Full ring integral | Requires numerical convolution |

**Conclusion:** QNG does NOT automatically predict flat rotation curves from a point-source
or ring-source Yukawa. Flat curves require either (a) λ >> R_galaxy and a specific
source distribution, or (b) a non-Yukawa mechanism. This is now a sharp theoretical
question, not a parameter-fitting problem.
