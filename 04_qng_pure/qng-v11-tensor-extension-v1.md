# DER-QNG-072 — QNG v11 tensor extension

## Motivation

DER-QNG-071 proves rigorously that a substrate with only scalar fields
per node cannot host a propagating spin-2 mode. CPU-121 confirms this
numerically on a ring background: mode spectrum exhibits cubic-symmetry
degeneracies (1, 2, 1, 1, 1, 2, ...) but not the uniform 2-fold
polarization pairing that would signal an emergent tensor graviton.

Consequently, closing Gap 12 requires **new ontology carrying a rank-2
tensor index structure at each point**. We add the minimal such
structure.

## Definition (v11 extension)

### Fields

All v10 scalar fields are preserved: `(sigma_g, sigma_m, phi, chi)`
per node. We add:

**Definition 1** (tensor field): At each lattice node `n`, a
symmetric rank-2 tensor field

```
h_ij(n)   with i, j ∈ {1, 2, 3}, h_ij = h_ji
```

with 6 independent real components. At linearized level we impose the
trace condition

```
h^k_k(n) := sum_i h_ii(n) = 0      (traceless)
```

leaving 5 independent components. The transverse-traceless projection
is imposed at the level of EOM by gauge fixing (not as a structural
constraint).

**Interpretation**: `h_ij(n)` is the local traceless metric
perturbation around the flat Euclidean metric `delta_ij`. The conformal
mode (trace) is already carried by `sigma_g` via the Newtonian-gauge
relation `g_ij^conformal = (1 - 2Phi/c²) delta_ij`.

### Canonical momentum

Each component of `h_ij` has a conjugate momentum `pi_ij`:

```
pi_ij(n) := ∂L_h / ∂(∂_t h_ij)(n)
```

with the canonical commutator at the quantum level

```
[ h_ij(n), pi_kl(m) ] = i hbar * (1/2)(delta_ik delta_jl + delta_il delta_jk - (2/3) delta_ij delta_kl) * delta_nm
```

(the projection onto the traceless-symmetric subspace).

### Lagrangian (free)

```
L_h = (1/2) pi^ij pi_ij / mu_h - (1/2) c_g^2 (partial_k h_ij)(partial^k h^ij)
```

with `mu_h` = effective inertia for `h_ij`. Same functional form as
linearized GR in TT gauge.

### Dispersion

Free-field plane-wave solutions `h_ij(x,t) = h0_ij * exp(i(k·x - ωt))`
satisfy

```
omega^2 = c_g^2 * |k|^2
```

giving a MASSLESS propagating mode. After imposing the transverse
condition `k^i h_ij = 0` and traceless `h^i_i = 0`:

- Symmetric rank-2: 6 components
- Traceless: removes 1 → 5
- Transverse in 3D (2 conditions k^i h_ij = 0): removes 2 → **3**

Wait — this gives 3 DOF per `k`, not 2. Let me address this.

**Correction**: In 3D linearized gravity (spatial formulation), the
physical DOF count depends on gauge. For massless spin-2:

- Physical DOF = 2 (h+, h_x) per wavevector — this is the 4D Lorentz count.
- In 3D+1, the full theory has 2 TT modes; h_ij spatial perturbation
  with 6 symmetric components reduces to 2 after imposing:
  (a) tracelessness (1 condition)
  (b) transversality k^i h_ij = 0 (3 conditions, but one is trivial
      given tracelessness, net 2 conditions)
  Total: 6 - 1 - 2 = 3. Wait, that's 3 — but GR says 2.

**Careful**: The spatial-only tensor `h_ij` has 6 components. In a
FULLY COVARIANT 4D formulation, there are 10 = 6 + 4 from h_00 and
h_0i. Gauge symmetry (diffeomorphisms) removes 4 × 2 = 8 gauge-redundant
components → 2 physical.

In a SPATIAL-ONLY formulation with h_00 and h_0i ALREADY absorbed into
sigma_g scalar (Newtonian gauge), we work with h_ij. Remaining gauge
freedom: spatial diffeomorphisms generated by xi^i (3 parameters),
which act as h_ij → h_ij + ∂_i xi_j + ∂_j xi_i. Gauge orbit dimension
= 3. Physical DOF = 6 - 3 = 3 ... still 3.

For massless spin-2, restricting to transverse diffeomorphisms only
(longitudinal part absorbed in sigma_g), we have spatial diffeo
parameters xi^T_i with k_i xi^T_i = 0, i.e., 2 parameters. Then
physical DOF = 6 - 1 (trace) - 2 (transverse xi) = **3**. Hmm.

Actually in standard GR TT decomposition of h_ij:
- Scalar sector (trace + longitudinal): 2 scalars
- Vector sector: 1 transverse vector (2 components)
- Tensor sector: 1 TT tensor (2 components)

Total: 2 + 2 + 2 = 6 ✓. After gauge fixing in 3D diffeomorphisms (xi_i
with 3 components = 2 transverse + 1 longitudinal):

- Scalar sector: 2 - 1 gauge = 1 physical + 1 trace removed = 0 propagating
- Vector sector: 2 - 2 gauge = 0
- Tensor sector: 2 TT — **2 physical propagating**

Total physical propagating: 2 ✓ (matches GR h+, h_x).

So **h_ij restricted to TT sector after gauge fixing has 2 physical
propagating modes**, consistent with GR's massless spin-2.

### Couplings

**To sigma_m matter**:
```
L_int = (8 pi G_QNG / c^4) * h_ij * T^TT_ij[sigma_m]
```

where `T_ij[sigma_m]` is the sigma_m stress-energy tensor, and
`T^TT_ij` is its transverse-traceless projection. This matches the
linearized Einstein equation source.

**To sigma_g potential**: at linearized level, h_ij does NOT directly
couple to sigma_g — they are in separate sectors (conformal vs TT).
Non-linear corrections mix them (full GR).

## Dispersion check

Free h_ij EOM from L_h above:

```
(1/c_g^2) ∂_t^2 h_ij - nabla^2 h_ij = 0
```

Plane wave: `h_ij = h0_ij exp(i(k·x - omega t))`, with `h0_ij` symmetric,
traceless, transverse:

```
omega^2 = c_g^2 * |k|^2
```

Same speed as sigma_g scalar wave (and sigma_m and phi via DER-QNG-042
§3.3). Consistent with GW170817 constraint c_g = c.

Two physical components `(h+, h_x)` — matches GR exactly.

## Quadrupole formula

The GR quadrupole radiation formula follows from coupling `h_ij` to
`T^TT_ij` via standard linearized Einstein equation. For a source with
mass quadrupole moment `Q_ij(t) = integral (3 x_i x_j - r^2 delta_ij) rho d^3x`,
the radiated power is

```
P = (1/5) * (G/c^5) * <...Q_ij...Q^ij>
```

In v11 natural units, using derived G and c values, this should match
the GR prediction for binary pulsars (e.g., PSR B1913+16 orbital decay
rate).

## Why this is minimal

Alternative: Regge-calculus edge lengths (scalar per edge). In 3D cubic
lattice with 3 principal edges per node, this adds 3 scalars per node.
But transforms as a vector under rotations (not a tensor), giving
spin-1 graviton-like — wrong.

To get spin-2 from edge-valued fields, need edge lengths in a
TRIANGULATED lattice (simplicial complex) with 6 edges per tetrahedron,
giving tensor metric from law-of-cosines. This is more complex
ontologically but equivalent at linearized level.

The node-valued symmetric tensor `h_ij` is the DIRECT representation
and is minimal for our purposes.

## Non-minimality caveats

v11 adds 5 real components per node (h_ij traceless). This is a
significant ontological extension of v10 (which had 4 scalars per
node). Physical interpretation: h_ij encodes the local FRAME deformation
— the direction-dependent difference between lattice edges that would
arise if edges could "stretch" anisotropically.
