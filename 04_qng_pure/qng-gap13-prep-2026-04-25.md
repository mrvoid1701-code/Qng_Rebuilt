## 1-loop χ-tadpole structure

```
δα_χ(L) = DELTA² × ∫_{|k|<1/L}^{Λ_UV} d³k/(2π)³ × G_χ(k)
```

where:
- `G_χ(k) = 1/(CHI_DECAY + (CHI_REL/z) k²)` is χ propagator
- IR cutoff at `1/L` (modes integrated below scale L are encoded in
  effective action at L)
- UV cutoff at lattice `Λ_UV = π/a_L`

Crossover scale: `k_c = √(z·CHI_DECAY/CHI_REL)`. For QNG default
parameters (z=6, CHI_DECAY=0.020, CHI_REL=0.35): `k_c ≈ 0.585`.

## Running of α at low-IR / high-UV regimes

**Low-momentum regime** (k < k_c):
```
G_χ(k) ≈ 1/CHI_DECAY  →  ∫ k²dk/CHI_DECAY ~ k³/3·CHI_DECAY
```

So contribution from modes below 1/L:
```
δα_below(L) ~ (1/L)³/(3·CHI_DECAY)
```

This means α(L) runs as **1/L³** at scales L > 1/k_c ≈ 1.71 lattice units.

**High-momentum regime** (k > k_c):
```
G_χ(k) ≈ z/(CHI_REL·k²)  →  ∫ k²·z/(CHI_REL·k²) dk = z·k/CHI_REL
```

This contributes a CONSTANT (not running) term ∝ z·Λ_UV/CHI_REL.

## Implication for Gap 13

The breakthrough hypothesis (DER-QNG-079) required **α(L) ~ 1/L²** to
match observed Λ at Hubble scale. 1-loop χ-tadpole gives **α(L) ~ 1/L³**.

**1-loop χ-tadpole is the WRONG power law to vindicate breakthrough.**
